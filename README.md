# NextWatch Android

Personal entertainment recommendation app for anime, TV series and movies.

## V0.1.0
- Native Android interface
- Local persistent ratings, watchlist and watched history
- Personal match scoring
- Local recommendation engine
- Taste DNA
- Taste Check / Review Audit
- Trailer search
- Backup export/import
- Spoiler Shield preference

## Data privacy
Personal viewing data is stored locally on-device. Do not commit personal profile exports into this public repository.

## Build
GitHub Actions builds the debug APK on every push to `main`.
